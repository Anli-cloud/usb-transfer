# USB Transfer

USB 文件传输工具，用于在 Android 手机和 Windows 电脑之间传输录屏、截图、测试包和其他文件。

适用于 64 位 Windows 10/11 与支持 USB MTP 文件传输的 Android 手机。

1. 如果旧版还在运行，先在托盘菜单中选「退出」。双击下载的客户端，工具启动后会在 Windows 通知区域运行。
2. 用支持数据传输的 USB 线连接手机，解锁并选择「文件传输」。Windows 识别到手机的文件传输接口后，工具会自动打开「最近新增」。
3. 点击「保存目录…」指定电脑上的接收位置。Android 一旦通过 USB 提供新录屏或截图，弹窗先显示「准备中」。文件就绪后，两个复制按钮启用，弹窗开始 10 秒倒计时。
4. 「保存并复制」把原件存进保存目录并复制文件。「仅复制」使用应用的本地临时副本。复制完成后，可在资源管理器或支持粘贴文件的应用中按 `Ctrl+V`。
5. 「最近新增」默认显示最近 1 天的最新 10 条。首次检索会先显示已经找到的文件，结果随检索继续更新。可切换最近 3 天或 7 天，并点「加载剩余」展开当前筛选的其他记录。
6. 选中录屏、视频或图片后点「预览」，可选「内置预览」或「Windows 打开方式」。列表支持批量保存和管理电脑副本。需要反向传输时，点击「发送到手机」，文件会放在手机的 `Download/测试传输`。

关闭主面板会收起到托盘。在托盘菜单中选「退出」可结束后台运行。重新启动 Windows 后，需再次打开程序。

如果需要长期保留文件，使用「保存并复制」。工具启动时会清理超过 24 小时的临时副本。

文件传输通过 Windows Portable Devices 接口走 USB。工具按接收到的原始字节保存。如果手机的 USB 设置有「将视频转换为 AVC」，请保持关闭。 [Android USB 转码设置](https://source.android.com/docs/core/media/media-transcoding)

如果刚录好的视频没有显示，点「刷新」并选择「全部类型」，也可以在「视频」里找。日期带「检测」的条目采用电脑首次识别到该文件的时间。工具能读取 Android 通过 USB 文件传输开放的目录。

## 内置视频预览

- `←` 或 `A` 向后跳 5 秒，`→` 或 `D` 向前跳 5 秒。长按约 350 毫秒后以 2 倍速快退或快进，松开恢复之前的播放或暂停状态。
- `↑`、`W` 或向上滚动提高音量，`↓`、`S` 或向下滚动降低音量。每次按键或每格滚轮调节 5 个百分点。
- 按住 `Ctrl` 滚动可在 100% 至 400% 之间缩放画面。拖窗口边缘或右下角可调整预览大小，视频随窗口等比缩放。
- 拖进度条可定位到任意播放位置。

## 从源码构建

将源码解压到本地目录，在 PowerShell 中执行 `./build.ps1`。构建使用 Windows 自带的 64 位 .NET Framework C# 编译器，不需要下载依赖。生成的程序在 `build/USBTransfer.exe`。
